## 1. Direction & feel

A boutique-editorial register — a tailor's order book reimagined as a web app. The warm-white surface gives the screen the off-white tone of cotton paper, the deep midnight navy chrome anchors the rail and top bar like a leather-bound spine, and the terracotta accent carries the warmth of a fountain-pen flourish: handmade, unmistakably human. Sage as the positive signal keeps confirmations grounded rather than chirpy; danger red is pulled toward terracotta so even errors stay inside the palette's emotional register. For a fabric retailer this reads as *craft*, not *enterprise software* — the same warmth as the bolts of fabric the app tracks.

**Anti-patterns**: AI purple/pink gradients · neon/synth accents · pure neutral grey chrome · saturated tech-blue links · glassmorphism · 3D depth · dark mode by default.

## 6. Motion

### 6.1 Durations

| Token | ms | Use |
|---|---|---|
| `75` | 75 | Input focus color tween |
| `150` | 150 | Hover transitions, instant feedback |
| `200` | 200 | Standard transitions, page enter, tab indicator slide |
| `300` | 300 | Drawer/modal open |
| `500` | 500 | Decorative, never functional |

### 6.2 Easings

| Token | cubic-bezier | Use |
|---|---|---|
| `standard` | `cubic-bezier(0.4, 0, 0.2, 1)` | Default transitions |
| `decelerate` | `cubic-bezier(0, 0, 0.2, 1)` | Enter / open / appear |
| `accelerate` | `cubic-bezier(0.4, 0, 1, 1)` | Exit / close / dismiss |
| `emphasized` | `cubic-bezier(0.2, 0, 0, 1)` | Active indicator slide, key UI affordances |

### 6.3 Reduced-motion scope

- `[data-motion="reduced"]` descendant selector collapses durations to 1ms and removes transform-based motion.
- `@media (prefers-reduced-motion: reduce)` globally does the same.
- **POS is wrapped in `data-motion="reduced"`** (Phase 3) — only the functional success-flash / error-shake / focus border tween still run.

## 9. Typography

### 9.1 Family

```
font-family: "IBM Plex Sans Arabic", "IBM Plex Sans", system-ui, sans-serif;
```

Self-hosted via `@fontsource/ibm-plex-sans-arabic` + `@fontsource/ibm-plex-sans` (woff2, `font-display: swap`, with `unicode-range` from upstream). Arabic glyphs render in IBM Plex Sans Arabic; Latin/digit glyphs fall through to IBM Plex Sans automatically via the font-family stack.

### 9.2 Weights

| Weight | Value | Use |
|---|---|---|
| `light` | 300 | Decorative headings only — rare |
| `normal` | 400 | Body text |
| `medium` | 500 | Form labels, secondary headings, emphasized inline |
| `semibold` | 600 | Section headings, primary numerics, active states |
| `bold` | 700 | Page titles, hero text, brand wordmark |

### 9.3 Scale

| Class | Size | Line-height | Use |
|---|---|---|---|
| `text-xs` | 12px | 16px (1.33) | Metadata, captions, smallcaps labels |
| `text-sm` | 14px | 20px (1.43) | Body small, table cells, helper text |
| `text-base` | 16px | 24px (1.50) | Body default — mobile minimum |
| `text-lg` | 18px | 28px (1.56) | Card titles, large body |
| `text-xl` | 20px | 28px (1.40) | Section titles, card metric values |
| `text-2xl` | 24px | 32px (1.33) | Page sub-titles, large totals |
| `text-3xl` | 30px | 36px (1.20) | Section headers, large metric values |
| `text-4xl` | 36px | 44px (1.22) | Treasury balance values |
| `text-5xl` | 48px | 52px (1.08) | Hero / login title only |

### 9.4 Numbers

Apply `font-variant-numeric: tabular-nums` to every numeric cell in tables and finance views. Exposed as utility `.tabular-num` and as Tailwind plugin once needed (Phase 5).

### 9.5 RTL discipline

- Numeric input values stay LTR even inside RTL containers: `unicode-bidi: plaintext` on `<input type="number">`.
- Currency suffix "ج.م" — set on its own `<span>` with `font-weight: 400` and one step smaller than the number.
- Digits are Western (0–9). Never Arabic-Indic.

## 10. Patterns (Re-Skin Standard summary)

See [`RMX_UI_Redesign_Plan.md`](../RMX_UI_Redesign_Plan.md) §"Re-Skin Standard" for full pattern definitions. Reference points for Phase 3+ work:

- **Cards** — `surface-elevated` + `radius-lg` + `border-subtle` 1px + `shadow-sm` rest → `shadow-md` hover.
- **Section headers** — title `text-3xl` weight 600 + one-line subhead `text-muted text-sm`.
- **Tables** — sticky header, zebra rows via `surface-row-alt`, row hover `surface-hover`, per-row 3-dot action menu, RTL column order.
- **Inputs** — `radius-md`, 1px `border-default`, 2px `accent` focus ring, label above (`text-sm` weight 500), helper below (`text-tertiary`).
- **Buttons** — primary `accent` fill, secondary `surface-elevated` + `border-default`, tertiary text-only. Explicit hover / active / focus / disabled / loading states.
- **Status pills** — `pill` radius, `<semantic>-subtle` background, `<semantic>-foreground` text.

## 11. Decisions captured

- **Chrome and accent are separate.** Existing `--color-primary` (used as the "active link" color in Phase 0 components) is **revalued to terracotta** in Phase 1 so legacy components inherit the new accent — but the real dark chrome (`--rmx-chrome` `#16213A`) lives in a new token that the Phase 2 shell uses directly.
- **Old token vocabulary stays.** `--color-canvas`, `--color-ink`, `--color-primary`, etc. are kept and **revalued** (not deleted). New `--rmx-*` tokens added alongside. Phase 7 retires legacy tokens once all components have been re-skinned.
- **Fonts via `@fontsource/*` npm packages**, not `public/fonts/` woff2 files. Same effect (self-hosted in the bundle, `unicode-range` correct, `font-display: swap`) with cleaner dependency management.
- **Logos are text-based placeholders** in this commit (`<text>` SVG using IBM Plex Sans). Replace with the actual RMX wordmark when artwork is supplied — paths and viewBoxes will not change.
